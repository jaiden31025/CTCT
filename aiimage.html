AI IMAGE GENERATION

About the Program

Students in the AI Image Generation program will learn the ins and outs of Image Generation, and will learn how diffusion models create images out of noise patterns. Students will master prompt creation, generator configuration, and will create their own Image Generator.



Course Descriptions

PROG201 Introduction to Python w/ Linear Algebra +

Students will be introduced to the basics of Python programming, working with multi-dimensional vectors, and core programming topics. Students will use basic Python libraries to draw graphics to the screen, and will learn basic concepts in machine learning.

AI101 Introductory Vibe Coding +
AI102 Prompting +

Entering their Senior year, Students will learn advanced prompting techniques to optimize image generation, students will configure and train diffusion models to fit project needs and will use these skills to create AI Generated Advertisments for a local buisiness — without pay —, and will create a final project portfolio to present infront of the entire school.

AI103 Diffusion Models and Tokenization +

Ending their Senior year, students will learn all about Tokenization, breaking Images down into noise, and the inner workings of a diffusion model. Students will be tasked on writing an 8-page research paper on image generation technology, and will create their own elementary diffusion model.
