AI & ELECTRON DEVELOPMENT

About the Program

Students in the AI & Electron Development program will learn the artful skill of Vibe Coding, Javascript, and poorly optimized core system utilities. Students will master are powerful low-level languages like HTML, Javascript, and Javascript.



Course Descriptions

PROG101 Introduction to Javascript +

Students will learn the basic syntax of the Javascript Language, how to interact with the dom, and how to execute JS outside of a browser using Node JS. In groups students will work together using Javascript to solve real world computational issues, and will present their solutions to a counsil of experts.

PROG102 User Interfaces with React JS +

As the second semester section, Students will expand their JS knowledge to the realm of frameworks. Students will learn the basics of jQuery, React JS, and React Native, and will apply these frameworks to create corporate and clean static webpages and web apps.

PROG103 App Development With Electron +

Entering their Senior year, Students will further their understanding of Javascript into the creation of multiplatform applications with Electron JS, and will learn about basic APIs and network protocols. Students will be hired on by a local buisiness — without pay — to create a modern application for them, Students will also complete a final semester long research project and project portfolio to present infront of the entire school.
